Mal Griot

A live musical performance built from voice, rhythm, looping, poetry and improvisation.

Queens-raised, India-based, trails blazed. Original songs, covers, and spoken word all run through the same practice: voice, loop pedal, and a lifetime moving through different Western genres, arranged live and shaped to the room rather than played the same way twice. Presence over polish. The room finishes the song.

Voice, rhythm, looping and poetry — built live, for the room, every time.

The sets

Four formats built from the same practice — chosen by room size and brief, not sold off a fixed menu.

Solo live set Solo — voice, loop pedal, keys

Original music built in real time: vocals, a loop pedal and keys stacking into full arrangements with nothing pre-recorded. The core format for club nights, curated series and festival slots.

Acoustic / intimate Solo or duo — voice-led

Stripped back for smaller rooms and seated audiences — voice up front, minimal rig, built for listening rather than volume. Right for listening rooms, private events and gallery bills.

Full performance Full band — voice, percussion, additional players

The developed version: percussion and additional musicians alongside Mal, movement, and a set arc built for a longer, headline-length slot on a proper stage.

Custom set Scaled to the brief

Built around a specific theme, programme or space — from a themed festival commission to a private booking with its own requirements. Lineup and length are set case by case.

A song can be performed. A room can be performed with.

Mal builds performances in real time — layering voice, rhythm, poetry and instinct into something that only exists for the people in the room.
