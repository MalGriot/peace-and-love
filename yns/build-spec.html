Database

04

Supabase (Postgres) project

Single free-tier project through community launch; upgrade tier when retail goes live.

Phase 1

Genre & content tables

Genre taxonomy, community posts, DJ bios, event/safety copy — all queryable by genre-world.

Phase 1

Catalog & order tables

Products, variants, inventory counts, orders, and line items — all settled through the Yass & Sass entity for clean tax and finance.

Phase 2

Profile tables

Shopper profile fields linked 1:1 to Supabase Auth users.
